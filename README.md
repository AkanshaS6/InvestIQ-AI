AI Powered Investment Research Platform

## Tech Stack
- Next.js
- Express.js
- Gemini AI
- LangChain
- Axios

## Features
- Company Research
- Financial Analysis
- Market News
- Risk Analysis
- AI Investment Decision

## Setup

### Client
cd client
npm install
npm run dev

### Server
cd server
npm install
npm run dev

Create a .env file:

GOOGLE_API_KEY=your_api_key
